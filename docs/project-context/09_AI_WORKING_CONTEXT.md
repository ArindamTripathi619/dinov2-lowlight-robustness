## 1. What this project is, in one paragraph

A **research study** investigating how a frozen DINOv2 (ViT-S/14, with a
ViT-B/14 replication) degrades under synthetic low-light corruption on CIFAR-10, where in
the network that degradation lives, and whether a diagnostic-guided LoRA adapter can
mitigate it cheaply. It is organized as three phases — **measure** (Phase 1:
accuracy/noise curves), **localize** (Phase 2: per-layer CKA / frequency / mechanism),
**remediate** (Phase 3: enhancement baselines, readout repair, LoRA allocation) — plus a
real-dark **ExDark** sim-to-real boundary study. Results feed a CVPR-style paper
(`paper/`) and a 14-section presentation deployed as a static site (`index.html`, built from `apps/presentation.py`).

## 6. Conventions & gotchas

- **No comments in new code unless asked** — repo code is comment-light/deliberate.
- **Never hand-edit** `paper/results/*.tex`, `paper/figures/*`, or `results_pilot/numbers.tex`
  — all are auto-generated by `make_paper_{tables,figures}.py`.
- **Corruption protocol is seeded** (`1000 + severity`). Upstream's deterministic-noise
  primitive was deliberately *not* ported to keep byte-comparability. Don't "fix" this
  without re-baselining everything.
- **`upstream_src/` is dead** (byte-identical to `src/`, zero references). Ignore it;
  do not "sync" it.
- **Two requirements files:** `requirements.txt` (runtime incl. torch) vs
  `requirements-audit.txt` (torch-free, what CI audits).
- Config is the single source of truth; the harness embeds its SHA-256 into the results
  manifest, so changing a config invalidates prior runs by design.

## 7. Known sharp edges (see `07_TECHNICAL_DEBT_AND_OPEN_QUESTIONS.md`)

- `src/lora.py:73-74` uses global `np.random` inside a `num_workers=2` DataLoader →
  correlated augmentation streams (workaround exists in `run_lora_simple_colab.py`).
- `src/lora.py:138` `apply_lora` mutates in place (latent footgun; no active caller affected).
- `analyze_seeds.py:97,99` can `TypeError` on logs missing a `severity 0:` line.
- `run_notebook3.py` omits 3 CSVs its Colab/notebook counterparts emit.
- Paper full-scale numbers are marked pending; pilot artifacts back the current text.
